# Why Power BI?

- **Speed**
- **User Friendly**
- **Eye-catching and Interactive Dashboards**
- **Maximum Features** (functions, visuals)
- **Cost** – cheapest tool
- **Data connectivity** – can connect to ~100 data sources

# How Power BI Works?

- **Power BI Desktop** – used to create reports  
- **Power BI Service** – used to publish the report
# Power BI is a collection of components:

- **Power Query** – for cleaning the data  
- **Power Pivot** – creating relationships between multiple data sources  
- **Power View** – to create different types of charts  
- **Power BI Service** – a SaaS-based online service to share reports

# Comparison: Tableau vs Power BI

| **Feature** | **Tableau** | **Power BI** |
|------------|-------------|--------------|
| **Data Visualization** | Industry-leading visualization tool with highly advanced, customizable, and interactive visuals. Great for complex analytics dashboards. | Strong visualization capabilities, but slightly less advanced than Tableau. Very good for business reporting with integrated data modeling. |
| **Backend / Data Modeling** | Limited data modeling features (requires Tableau Prep or external tools). | Powerful data modeling using Power Query + DAX (similar to Excel formulas but more advanced). |
| **Size of Dataset** | Can handle very large datasets efficiently, especially with Hyper Engine. | Free version has a **1 GB limit per dataset**. Pro and Premium allow much larger datasets. |
| **Data Sources** | Connects to a very wide range of databases, cloud sources, and big-data systems. Excellent at live connections. | Supports most common data sources, especially Microsoft ecosystem (Azure, SQL Server, Excel, SharePoint). Live and direct query supported. |
| **Costing** | More expensive. <br> **Tableau Creator**: ~USD 70/user/month. <br> **Tableau Viewer/Explorer** also cost additional. | Cheaper. <br> **Power BI Desktop**: Free. <br> **Power BI Pro**: ~USD 10–15/user/month. <br> **Premium Per User** available for advanced features. |
| **Ease of Use** | Steeper learning curve for beginners. | Easier for Excel users; more beginner-friendly. |
| **Deployment Options** | Strong enterprise deployment features, including on-prem (Tableau Server). | Cloud-first (Power BI Service). On-prem available via Power BI Report Server (Premium). |
| **Performance** | Very fast in handling large datasets with Hyper Engine. | Performs well, but extremely large datasets may require Premium capacity. |
