# Why Power BI?

- **Speed**
- **User Friendly**
- **Eye-catching and Interactive Dashboards**
- **Maximum Features** (functions, visuals)
- **Cost** – cheapest tool
- **Data connectivity** – can connect to ~100 data sources

# How Power BI Works?

- **Power BI Desktop** – used to create reports  
- **Power BI Service** – used to publish the report
