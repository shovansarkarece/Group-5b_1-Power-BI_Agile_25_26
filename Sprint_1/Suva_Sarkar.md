# Why Power BI?

- **Speed**
- **User Friendly**
- **Eye-catching and Interactive Dashboards**
- **Maximum Features** (functions, visuals)
- **Cost** – cheapest tool
- **Data connectivity** – can connect to ~100 data sources

# How Power BI Works?

- **Power BI Desktop** – used to create reports  
- **Power BI Service** – used to publish the report
# Power BI is a collection of components:

- **Power Query** – for cleaning the data  
- **Power Pivot** – creating relationships between multiple data sources  
- **Power View** – to create different types of charts  
- **Power BI Service** – a SaaS-based online service to share reports

# Comparison: Tableau vs Power BI

| **Feature** | **Tableau** | **Power BI** |
|------------|-------------|--------------|
| **Data Visualization** | Industry-leading visualization tool with highly advanced, customizable, and interactive visuals. Great for complex analytics dashboards. | Strong visualization capabilities, but slightly less advanced than Tableau. Very good for business reporting with integrated data modeling. |
| **Backend / Data Modeling** | Limited data modeling features (requires Tableau Prep or external tools). | Powerful data modeling using Power Query + DAX (similar to Excel formulas but more advanced). |
| **Size of Dataset** | Can handle very large datasets efficiently, especially with Hyper Engine. | Free version has a **1 GB limit per dataset**. Pro and Premium allow much larger datasets. |
| **Data Sources** | Connects to a very wide range of databases, cloud sources, and big-data systems. Excellent at live connections. | Supports most common data sources, especially Microsoft ecosystem (Azure, SQL Server, Excel, SharePoint). Live and direct query supported. |
| **Costing** | More expensive. <br> **Tableau Creator**: ~USD 70/user/month. <br> **Tableau Viewer/Explorer** also cost additional. | Cheaper. <br> **Power BI Desktop**: Free. <br> **Power BI Pro**: ~USD 10–15/user/month. <br> **Premium Per User** available for advanced features. |
| **Ease of Use** | Steeper learning curve for beginners. | Easier for Excel users; more beginner-friendly. |
| **Deployment Options** | Strong enterprise deployment features, including on-prem (Tableau Server). | Cloud-first (Power BI Service). On-prem available via Power BI Report Server (Premium). |
| **Performance** | Very fast in handling large datasets with Hyper Engine. | Performs well, but extremely large datasets may require Premium capacity. |

# Microsoft Power BI – Installation & Pricing Guide

## 1. Overview  
Microsoft Power BI is a business analytics service that enables you to visualize your data and share insights across your organization — or embed them in an app or website.  
It consists of:  
- The desktop application (Power BI Desktop) for report creation.  
- The cloud service (Power BI Service) for sharing and collaboration.  
- Embedded and capacity-based licensing options for enterprise or embedded scenarios.

---

## 2. Installation

[Microsoft Power BI Desktop – Download](https://www.microsoft.com/en-us/download/details.aspx?id=58494)

## 3. Pricing & Licensing  
### 3.1 Official Pricing Overview  
Visit Microsoft’s official pricing page for the latest detailed pricing:  
[Power BI Pricing](https://www.microsoft.com/en-us/power-platform/products/power-bi/pricing) 

As of the current published pricing (USD region): 
- **Free**: Basic version, create reports in desktop, view personal content.  
- **Power BI Pro**: USD $14.00 per user/month (paid yearly) — enables publishing and sharing reports.  
- **Power BI Premium Per User (PPU)**: USD $24.00 per user/month (paid yearly) — advanced features, larger models, higher refresh rates.  
- **Power BI Embedded**: Variable pricing, contact sales for capacity-based embedding. :contentReference[oaicite:7]{index=7}

### 3.2 European (Germany) Example Pricing  
In Germany (EUR region) the pricing is approximately: 
- Power BI Pro: €13.10/user/month (annual billing)  
- Premium Per User: €22.50/user/month (annual billing)  
- Embedded / capacity-based: variable, contact Microsoft.

### 3.3 Licensing Details  
From Microsoft documentation:   
- Each user has a license (Free, Pro, or Premium Per User).  
- To publish content or share widely, a Pro or PPU license is needed (or content stored in Premium capacity).  
- Free users can view content if it’s stored in a Premium capacity workspace and they are given appropriate roles.  
- Capacity-based Premium licensing allows free users to consume content without each needing a paid license.

---

## 4. Choosing the Right License  
- **Free**: Good for individual use, exploring the tool, personal data analysis with Power BI Desktop and minimal sharing.  
- **Pro**: Suitable for teams that need to create, share and collaborate on reports and dashboards regularly.  
- **Premium Per User (PPU)**: Ideal for power users or smaller teams needing advanced features (large data models, higher refresh rates, AI features).  
- **Capacity / Premium (organization-wide)**: Best for large organizations needing enterprise-scale deployments, wide sharing of content (including free users), embedding in applications, or large data volumes.

## 7. Notes & Tips  
- Always check your *local currency and region* for exact pricing, as Microsoft lists are region-specific.  
- Some features may require the **Premium** tier or capacity options (e.g., very large dataset size, paginated reports, XMLA endpoint, unlimited sharing).  
- Organizations buying via enterprise agreements may have negotiated pricing or discounts.  
- Embedding scenarios (in apps/portals) frequently use the *Power BI Embedded* or *Capacity* models rather than per-user licensing.
