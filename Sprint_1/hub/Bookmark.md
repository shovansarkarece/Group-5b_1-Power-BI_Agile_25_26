## Overview

This document explains how **Bookmarks** are applied in Power BI to
create **interactive views of charts** within the same report. Bookmarks
allow users to save a specific state of a report page (filters, visuals,
slicers, and visibility) and switch between them with a single click.

## What is a Bookmark in Power BI?

A **Bookmark**: - Captures the **current state** of a report page -
Saves: - Filter selections - Visual visibility - Drill positions - Page
navigation - Allows users to create **interactive dashboards** - Works
like a **presentation mode** inside Power BI

------------------------------------------------------------------------

## Use Case in Your Report

In your dataset, Bookmarks are used to:

-   Switch between **different chart views**
-   Show or hide specific visuals
-   Control **user navigation**
-   Create an **interactive dashboard experience**

This allows end users to analyze data without changing filters manually.

------------------------------------------------------------------------

## What is Stored in the Bookmark?

Each Bookmark captures:

✅ Visual visibility
✅ Filter and slicer selection
✅ Drill-down/drill-through state
✅ Selected data points
✅ Page navigation position

------------------------------------------------------------------------

## How Bookmarks Work

1.  A user selects filters or changes visual states.
2.  A Bookmark is created and saved.
3.  When the bookmark button is clicked:
    -   The report instantly switches to that saved view.
4.  Multiple bookmarks allow multiple **predefined data views**.

------------------------------------------------------------------------

## Steps to Create Bookmarks in Power BI

1.  Open **Power BI Desktop**.
2.  Go to **View → Bookmarks Pane**.
3.  Apply filters or change visual visibility.
4.  Click **Add** to create a new Bookmark.
5.  Rename the Bookmark (e.g., Sales View, Profit View).
6.  Insert **Buttons** from the Insert tab.
7.  Assign Bookmarks to buttons using **Action Settings**.

------------------------------------------------------------------------

## Bookmark with Buttons (Interactive UI)

Buttons can be used as: - Navigation buttons - Toggle switches - View
changers - Chart switch buttons

This creates a **dashboard-like application experience** inside Power
