# 🔖 Power BI Bookmark -- Interactive View Control

## Overview

This document explains how **Bookmarks** are applied in Power BI to
create **interactive views of charts** within the same report. Bookmarks
allow users to save a specific state of a report page (filters, visuals,
slicers, and visibility) and switch between them with a single click.
