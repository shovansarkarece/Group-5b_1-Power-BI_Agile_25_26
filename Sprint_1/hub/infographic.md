# 💰 Power BI Infographic Chart -- Sum of Profit by Category

## Overview

This document explains how an **Infographic Chart** is imported and
applied in Power BI to visualize the **Sum of Profit by Category** using
**custom icons (currency symbols)** instead of standard bars. This type
of visual makes financial data more engaging and visually intuitive.

## Visual Description

The visual used is an **Infographic Chart** with the following
configuration:

-   **Category (X-axis):** Category
    -   Technology
    -   Office Supplies
    -   Furniture
-   **Measure (Y-axis):** Sum of Profit
-   **Visual Style:** Currency/Money icons
-   **Chart Purpose:** Visual comparison of profit using symbolic
    representation

------------------------------------------------------------------------

## What is an Infographic Chart in Power BI?

An Infographic Chart: - Uses **icons, images, or symbols** instead of
normal bars/columns - Makes dashboards more **creative and
attention-grabbing** - Improves **non-technical user understanding** -
Is widely used for: - Financial dashboards - KPI storytelling -
Executive presentations

## Steps to Create Infographic Chart in Power BI

1.  Open **Power BI Desktop**.
2.  Click **Get More Visuals (AppSource)**.
3.  Search for **Infographic Designer / Infographic Chart**.
4.  Import the visual.
5.  Drag **Category** into the Category field.
6.  Drag **Sum of Profit** into the Measure field.
7.  Choose an appropriate **icon (Money, Dollar, etc.)**.
8.  Adjust scaling and layout for best appearance.
