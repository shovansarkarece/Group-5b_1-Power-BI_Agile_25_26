## Group By Table Created with Correct Aggregates
What it means: Summarize data by grouping rows and calculating totals, averages, counts, etc.
Steps:

In Power Query Editor, select your table
Go to Transform tab → Group By
Configure:

Group by: Select column(s) to group (e.g., "Product Category")
New column name: Give it a name (e.g., "Total Sales")
Operation: Choose aggregation (Sum, Average, Count, etc.)
Column: Select column to aggregate


Click OK
