## Create a Gauge Chart

Please follow the process below to create a Gauge chart -
- Click on the Gauge icon in the Visualizations pane (looks like a speedometer)
- Drag a numeric measure (like actual sales) to the "Value" field well (if necessary)
- Drag your target/goal value to the "Target value" field well (if necessary)
- Optionally, set minimum and maximum values in the field wells
- Format the gauge through Format visual → adjust colors, labels, and callout values

**Use case:** Great for showing progress toward a goal or KPI.
