**Task 1: Create a Map**

Please Follow the process below to create a map -
- Load your Excel data into Power BI Desktop (Home → Get Data → Excel)
- Once loaded, click on the Map icon in the Visualizations pane (looks like a pin on a globe)
- Drag your location field (like City, State, or Country) to the "Location" field well
- Optionally, add fields to "Legend" or "Tooltips" for more details
- Resize and position your map on the canvas

Note: Your location data needs to be recognizable geographic names for Power BI to plot them correctly.

**Task 2: Create a Filled Map**

Please Follow the process below to create a Filled Map -
- Click on the Filled Map icon in the Visualizations pane (looks like a shaded map)
- Drag your location field to the "Location" field well
- The map will shade different regions based on your data values
- Adjust colors through Format visual → Visual → Map settings

Difference from regular Map: Filled maps shade entire regions/countries, while regular maps show bubble points.

**Task 3: Create an Azure Map**

Please Follow the process below to create a Azure Map -
- Click on the Azure Map icon in the Visualizations pane (it will appear after importing)
- Drag your location field (like City, State, Country, or Address) to the "Location" field well
- Optionally, add fields to "Legend" (for color-coding categories) or "Tooltips" (for additional details on hover)
- Format the map through Format visual → Choose map style (Road, Satellite, Night, Grayscale, etc.)
- Resize and position your Azure Map on the canvas

Note: Azure Maps offers advanced features like satellite view, 3D buildings, and multiple map styles compared to the standard map visual. Ensure you have an internet connection for the map tiles to load properly.

**Key Differences: Azure Map vs. Regular Map:**
| Feature  | Regular Map | Azure Map |
|----------|----------|----------|
| Map styles    | Limited  | Multiple (satellite, night mode, etc.)   |
| Performance    | Good   | Better for large datasets  |
| Customization    | Basic  | Advanced  |
| 3D features    | No   | Yes  |
