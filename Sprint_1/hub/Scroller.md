## Visual Description

The visual used is a **Scroller (KPI-style text visual)** with the
following configuration:

-   **Metrics Displayed:**
    -   Sum of Sales
    -   Sum of Profit
-   **Category:** State
-   **Scrolling Animation:** Enabled
-   **Status Indicator:** Enabled (Green Up Arrow)
-   **Font Size:** 63
-   **Scroll Speed:** 2
-   **Update Interval:** 50 ms

## What is a Scroller Visual?

A Scroller visual: - Displays key values in a **moving text format** -
Updates values dynamically - Acts as a **ticker-style KPI** - Is best
used for: - Sales dashboards - Live monitoring screens - Executive
summary reports

## Steps to Create Scroller Visual in Power BI

1.  Import your dataset into Power BI.
2.  Go to **AppSource** and import the **Scroller visual**.
3.  Drag **Sum of Sales** and **Sum of Profit** into the Value field.
4.  Drag **State** into the Category field.
5.  Open the **Format Visual** panel.
6.  Enable **Status Indicator**.
7.  Adjust **Font Size**, **Scroll Speed**, and **Update Interval**.
8.  Apply text and background colors as needed.
