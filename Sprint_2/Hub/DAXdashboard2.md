## Dashboard Overview

### Purpose
This dashboard provides deep insights into product performance and customer behavior with focus on:
- Product profitability and portfolio analysis
- Customer lifetime value and segmentation
- RFM (Recency, Frequency, Monetary) analysis
- Cross-table calculations using RELATED and RELATEDTABLE
- Customer retention and churn metrics
- Product affinity and basket analysis

### Key Metrics
- Customer Lifetime Value (CLV)
- Product Revenue, Profit, and Margin
- RFM Scores and Customer Segments
- Product Rankings and ABC Classification
- Customer Retention Rate
- Cross-category Purchase Rate

### Target Audience
- Marketing Team
- Product Managers
- Customer Success Team
- Sales Operations
- Business Strategy Team

## Data Model Requirements

### Required Tables

#### 1. Sales Table (Fact Table)
```
Columns:
- OrderID (Text/Number)
- ProductID (Text/Number) - Foreign Key
- CustomerID (Text/Number) - Foreign Key
- OrderDate (Date) - Foreign Key
- Amount (Currency/Decimal)
- Quantity (Whole Number)
- TransactionType (Text)
```

#### 2. Products Table (Dimension)
```
Columns:
- ProductID (Text/Number) - Primary Key
- ProductName (Text)
- Category (Text)
- SubCategory (Text)
- UnitCost (Currency/Decimal)
- ListPrice (Currency/Decimal)
```

#### 3. Customers Table (Dimension)
```
Columns:
- CustomerID (Text/Number) - Primary Key
- CustomerName (Text)
- Segment (Text) - e.g., "Premium", "Standard", "Basic"
- Region (Text)
- SignupDate (Date)
- Email (Text)
```

#### 4. DateTable (Dimension)
```
Columns:
- Date (Date) - Primary Key
- Year (Whole Number)
- Month (Whole Number)
- MonthName (Text)
- Quarter (Text)
- YearMonth (Text)
```

**DAX to Create DateTable:**
```DAX
DateTable = 
ADDCOLUMNS(
    CALENDAR(DATE(2020,1,1), DATE(2025,12,31)),
    "Year", YEAR([Date]),
    "Month", MONTH([Date]),
    "MonthName", FORMAT([Date], "MMM"),
    "Quarter", "Q" & QUARTER([Date]),
    "YearMonth", FORMAT([Date], "YYYY-MM")
)
```

### Required Relationships

```
Sales[ProductID]  → Products[ProductID]  (Many-to-One)
Sales[CustomerID] → Customers[CustomerID] (Many-to-One)
Sales[OrderDate]  → DateTable[Date]      (Many-to-One)
```

**Relationship Properties:**
- Cardinality: Many-to-One (*:1)
- Cross-filter direction: Single (from Sales to dimension tables)
- Active: Yes

## All DAX Measures

### SECTION 1: Cross-Table Base Measures (Using RELATED)

```DAX
// Product Cost (calculated column in Sales table)
// Business Logic: Retrieves unit cost from Products table for each sale
// Uses: Many-to-one relationship from Sales to Products
Product Cost = 
RELATED(Products[UnitCost])
```

```DAX
// Product Category (calculated column in Sales table)
// Business Logic: Brings product classification into sales context
Product Category = 
RELATED(Products[Category])
```

```DAX
// Customer Segment (calculated column in Sales table)
// Business Logic: Retrieves customer segmentation from Customers table
Customer Segment = 
RELATED(Customers[Segment])
```

```DAX
// Customer Region (calculated column in Sales table)
// Business Logic: Geographic classification for regional analysis
Customer Region = 
RELATED(Customers[Region])
```

```DAX
// Total Profit
// Business Logic: Calculates gross profit by subtracting cost from sales
// Cost is retrieved via RELATED from Products table
Total Profit = 
SUMX(
    Sales,
    Sales[Amount] - (Sales[Quantity] * RELATED(Products[UnitCost]))
)
```

```DAX
// Profit Margin %
// Business Logic: Profitability ratio showing profit as % of sales
// Key metric for pricing strategy and product mix optimization
Profit Margin % = 
DIVIDE(
    [Total Profit],
    [Total Sales],
    0
)
```

### SECTION 2: Product-Level Measures (Using RELATEDTABLE)

```DAX
// Total Units Sold (measure in Products table context)
// Business Logic: Sums quantity from all related sales records
// Uses: One-to-many relationship from Products to Sales
Total Units Sold = 
SUMX(
    RELATEDTABLE(Sales),
    Sales[Quantity]
)
```

```DAX
// Product Revenue (in Products table context)
// Business Logic: Total revenue generated by this product
Product Revenue = 
SUMX(
    RELATEDTABLE(Sales),
    Sales[Amount]
)
```

```DAX
// Product Profit (in Products table context)
// Business Logic: Total profit contribution from this product
Product Profit = 
SUMX(
    RELATEDTABLE(Sales),
    Sales[Amount] - (Sales[Quantity] * Products[UnitCost])
)
```

```DAX
// Average Sale Price (in Products table context)
// Business Logic: Mean selling price, may differ from list price
// Useful for discount analysis and price elasticity
Avg Sale Price = 
AVERAGEX(
    RELATEDTABLE(Sales),
    DIVIDE(Sales[Amount], Sales[Quantity], 0)
)
```

```DAX
// Times Ordered (in Products table context)
// Business Logic: Counts distinct orders containing this product
// Indicates product popularity and frequency of purchase
Times Ordered = 
DISTINCTCOUNTX(
    RELATEDTABLE(Sales),
    Sales[OrderID]
)
```

```DAX
// First Sale Date (in Products table context)
// Business Logic: When product first appeared in sales
First Sale Date = 
MINX(
    RELATEDTABLE(Sales),
    Sales[OrderDate]
)
```

```DAX
// Days Since Last Sale (in Products table context)
// Business Logic: Inventory relevance check
// High value indicates potential obsolescence
Days Since Last Sale = 
VAR LastSaleDate = MAXX(RELATEDTABLE(Sales), Sales[OrderDate])
RETURN
    IF(
        NOT(ISBLANK(LastSaleDate)),
        TODAY() - LastSaleDate,
        BLANK()
    )
```

### SECTION 4: Product Performance Ranking Measures

```DAX
// Product Rank by Revenue
// Business Logic: Ranks products within current filter context
// Used for: Top N analysis, ABC classification
Product Rank Revenue = 
RANKX(
    ALL(Products[ProductName]),
    [Product Revenue],
    ,
    DESC,
    DENSE
)
```

```DAX
// Product Rank by Profit
Product Rank Profit = 
RANKX(
    ALL(Products[ProductName]),
    [Product Profit],
    ,
    DESC,
    DENSE
)
```

```DAX
// Product Rank by Units Sold
Product Rank Units = 
RANKX(
    ALL(Products[ProductName]),
    [Total Units Sold],
    ,
    DESC,
    DENSE
)
```

```DAX
// Is Top 10 Product
// Business Logic: Boolean flag for filtering top performers
// Used for: Conditional formatting, dynamic filtering
Is Top 10 Product = 
[Product Rank Revenue] <= 10
```

```DAX
// Product Contribution to Total
// Business Logic: Percentage of total sales this product represents
// Used for: Pareto analysis (80/20 rule)
Product % of Total = 
DIVIDE(
    [Product Revenue],
    CALCULATE([Product Revenue], ALL(Products)),
    0
)
```

```DAX
// Cumulative % of Sales
// Business Logic: Running total of product contribution
// Used for: ABC classification (A=70%, B=20%, C=10%)
Cumulative % Sales = 
VAR CurrentProductRevenue = [Product Revenue]
VAR AllProductsRanked = 
    FILTER(
        ALL(Products),
        [Product Revenue] >= CurrentProductRevenue
    )
RETURN
    DIVIDE(
        SUMX(AllProductsRanked, [Product Revenue]),
        CALCULATE([Product Revenue], ALL(Products)),
        0
    )
```

```DAX
// Product Classification (ABC)
// Business Logic: A products = top 70% sales, B = next 20%, C = last 10%
Product Class = 
VAR CumPct = [Cumulative % Sales]
RETURN
    SWITCH(
        TRUE(),
        CumPct <= 0.7, "A - High Value",
        CumPct <= 0.9, "B - Medium Value",
        "C - Low Value"
    )
```

### SECTION 5: Customer Segmentation & RFM Analysis

```DAX
// Customer Rank by Value
Customer Rank = 
RANKX(
    ALL(Customers[CustomerID]),
    [Customer Lifetime Value],
    ,
    DESC,
    DENSE
)
```

```DAX
// Is Top 100 Customer
Is Top 100 Customer = 
[Customer Rank] <= 100
```

```DAX
// Customer Recency Score (1-5)
// Business Logic: Higher score = more recent purchase
// 5 = purchased in last 30 days | 1 = no purchase in 180+ days
Recency Score = 
VAR Days = [Days Since Last Purchase]
RETURN
    SWITCH(
        TRUE(),
        ISBLANK(Days), BLANK(),
        Days <= 30, 5,
        Days <= 60, 4,
        Days <= 90, 3,
        Days <= 180, 2,
        1
    )
```

```DAX
// Customer Frequency Score (1-5)
// Business Logic: Higher score = more frequent buyer
// Based on total number of orders
Frequency Score = 
VAR Orders = [Customer Total Orders]
RETURN
    SWITCH(
        TRUE(),
        ISBLANK(Orders), BLANK(),
        Orders >= 20, 5,
        Orders >= 10, 4,
        Orders >= 5, 3,
        Orders >= 2, 2,
        1
    )
```

```DAX
// Customer Monetary Score (1-5)
// Business Logic: Higher score = higher total spending
// Based on lifetime value percentile
Monetary Score = 
VAR CLV = [Customer Lifetime Value]
VAR TopQuintile = PERCENTILE.INC(ALL(Customers), [Customer Lifetime Value], 0.8)
VAR FourthQuintile = PERCENTILE.INC(ALL(Customers), [Customer Lifetime Value], 0.6)
VAR ThirdQuintile = PERCENTILE.INC(ALL(Customers), [Customer Lifetime Value], 0.4)
VAR SecondQuintile = PERCENTILE.INC(ALL(Customers), [Customer Lifetime Value], 0.2)
RETURN
    SWITCH(
        TRUE(),
        ISBLANK(CLV), BLANK(),
        CLV >= TopQuintile, 5,
        CLV >= FourthQuintile, 4,
        CLV >= ThirdQuintile, 3,
        CLV >= SecondQuintile, 2,
        1
    )
```

```DAX
// RFM Score (Combined)
// Business Logic: Concatenates R, F, M scores for segmentation
// "555" = Best customers | "111" = Worst customers
RFM Score = 
[Recency Score] & [Frequency Score] & [Monetary Score]
```

```DAX
// Customer RFM Segment
// Business Logic: Strategic segmentation for marketing campaigns
Customer RFM Segment = 
VAR R = [Recency Score]
VAR F = [Frequency Score]
VAR M = [Monetary Score]
RETURN
    SWITCH(
        TRUE(),
        R >= 4 && F >= 4 && M >= 4, "Champions",
        R >= 4 && F >= 3 && M >= 3, "Loyal Customers",
        R >= 4 && F <= 2 && M >= 3, "Big Spenders",
        R >= 3 && F >= 3 && M >= 3, "Potential Loyalists",
        R >= 4 && F <= 2 && M <= 2, "New Customers",
        R <= 2 && F >= 3 && M >= 3, "At Risk",
        R <= 2 && F >= 4 && M >= 4, "Can't Lose Them",
        R <= 2 && F <= 2, "Lost",
        "About to Sleep"
    )
```

```DAX
// Profit per Customer
// Business Logic: Average profitability per customer
// Used for: CAC (Customer Acquisition Cost) comparison
Profit per Customer =

    [Total Profit],
    DISTINCTCOUNT(Sales[CustomerID]),
    0
)
```

```DAX
// Profit per Order
// Business Logic: Average order profitability
// Used for: Shipping cost breakeven analysis
Profit per Order = 
DIVIDE(
    [Total Profit],
    DISTINCTCOUNT(Sales[OrderID]),
    0
)
```

```DAX
// Profit per Unit
// Business Logic: Average margin per item sold
Profit per Unit = 
DIVIDE(
    [Total Profit],
    SUM(Sales[Quantity]),
    0
)
```

```DAX
// Low Margin Products Count
// Business Logic: Counts products with margin below 20%
// Used for: Pricing strategy review
Low Margin Products = 
CALCULATE(
    DISTINCTCOUNT(Products[ProductID]),
    FILTER(
        Products,
        [Profit Margin %] < 0.2
    )
)
```

```DAX
// High Margin Products Count
High Margin Products = 
CALCULATE(
    DISTINCTCOUNT(Products[ProductID]),
    FILTER(
        Products,
        [Profit Margin %] >= 0.4
    )
)
```

```DAX
// Weighted Average Margin
// Business Logic: Average margin weighted by sales volume
// More accurate than simple average when products have varying sales
Weighted Avg Margin = 
SUMX(
    Products,
    [Product Revenue] * [Profit Margin %]

```

### SECTION 7: Customer Retention & Churn Metrics

```DAX
// Active Customers (Last 90 Days)
// Business Logic: Counts customers with recent purchase
Active Customers = 
CALCULATE(
    DISTINCTCOUNT(Sales[CustomerID]),
    DATESINPERIOD(
        'DateTable'[Date],
        MAX('DateTable'[Date]),
        -90,
        DAY
    )
)
```

```DAX
// New Customers (This Month)
// Business Logic: Counts customers with first purchase this month
New Customers = 
VAR CurrentMonth = MAX('DateTable'[Date])
RETURN
    COUNTROWS(
        FILTER(
            VALUES(Customers[CustomerID]),
            [Customer First Purchase] >= STARTOFMONTH(CurrentMonth) &&
            [Customer First Purchase] <= ENDOFMONTH(CurrentMonth)
        )
    )
```

```DAX
// Repeat Customer Rate
// Business Logic: % of customers who made multiple purchases
// Key indicator of customer satisfaction
Repeat Customer Rate = 
VAR TotalCustomers = DISTINCTCOUNT(Sales[CustomerID])
VAR RepeatCustomers = 
    CALCULATE(
        DISTINCTCOUNT(Sales[CustomerID]),
        FILTER(
            ALL(Customers),
            [Customer Total Orders] > 1
        )
    )
RETURN
    DIVIDE(RepeatCustomers, TotalCustomers, 0)
```

```DAX
// Customer Retention Rate (MoM)
// Business Logic: % of last month's customers who purchased this month
Customer Retention Rate = 
VAR LastMonthCustomers = 
    CALCULATE(
        VALUES(Sales[CustomerID]),
        DATEADD('DateTable'[Date], -1, MONTH)
    )
VAR ThisMonthCustomers = 
    VALUES(Sales[CustomerID])
VAR RetainedCustomers = 
    COUNTROWS(INTERSECT(LastMonthCustomers, ThisMonthCustomers))
RETURN
    DIVIDE(
        RetainedCustomers,
        COUNTROWS(LastMonthCustomers),
        0
    )
```

```DAX
// Churn Risk Customers
// Business Logic: Count of "At Risk" customers
Churn Risk Customers = 
CALCULATE(
    DISTINCTCOUNT(Customers[CustomerID]),
    Customers[Customer Status] = "At Risk"
)
```
